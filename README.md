# Calendar Digest

Сервис календарного дайджеста из iCloud и трёх аккаунтов Mail.ru.
Включает чтение CalDAV, подготовку HTML-письма и защищённые страницы
подтверждения, переноса и отмены событий с учётом возможностей провайдера.

## Размещение

Следуйте [пошаговой инструкции Render](docs/render-walkthrough.md).
Файл `render.yaml` задаёт один Python-сервис с постоянным диском.
Учётные данные вводятся в переменные окружения Render, не в исходники.

Сборка и автоматические проверки:

```sh
bash scripts/setup.sh
```

Данные календарей и база действий сохраняются в `DIGEST_STATE_DIR`;
на Render это `/var/data`. Для локальной разработки используется `.local/`,
исключённая из Git.

## Текущий этап

Веб-сервис действий работает на Render. Проверены чтение четырёх аккаунтов,
перенос и отмена личного события первого аккаунта Mail.ru; отменённое событие
удалено из календаря и сохранено в истории дайджеста без кнопок. Также проверено
принятие приглашения вторым аккаунтом Mail.ru: ответ виден организатору
в первом аккаунте. Эти проверки не распространяются на все действия всех провайдеров.

SMTP-отправка через Яндекс проверена настоящим письмом: владелец подтвердил
получение, оформление и работу кнопок. Ежедневная отправка в **17:00 по Москве**
одобрена и включена 15 октября 2026 года; проверена свежая отметка работы
планировщика. Получение первой отправки по расписанию ещё не подтверждено.
Для нового размещения расписание по умолчанию выключено; настройка и проверка
описаны в [email-delivery.md](docs/email-delivery.md).

Проверочное push-уведомление через Pushover получено и расшифровано на iPhone
15 октября 2026 года. Предпросмотр поручений проверен владельцем; ожидаемые
дни рождения формируются на iPhone из Контактов и не поступают из текущих
подключённых календарей. Владелец подтвердил, что контакты хранятся в iCloud.
Добавлено отдельное чтение дней рождения из iCloud Contacts через CardDAV
с существующим паролем приложения. Чтение и расчёт напоминаний проверены
в среде разработки без отправки. Источник по умолчанию выключен
(`ICLOUD_CONTACT_BIRTHDAYS_ENABLED=false`); подключение на Render и новый
предпросмотр ещё не подтверждены. Автоматические push остаются выключенными
до проверки дней рождения и одобрения нового предпросмотра.

Добавлены сохранение очереди напоминаний, чтение изменений календарей и
отдельный круглосуточный планировщик push. Автоматическая отправка по умолчанию
выключена (`PUSH_SCHEDULE_ENABLED=false`) и пока не подтверждена на действующем
сервисе. Порядок проверки расписания, подготовки очереди и включения описан
в [push-notifications.md](docs/push-notifications.md). Настройка push сохраняет
действующее расписание почтового дайджеста.

Этот пакет содержит необходимые для развёртывания исходники и проверки.
Локальные данные аккаунтов, образцы писем и диагностическая история
разработки в пакет не включены.
